# AgriVision AI – Plant Disease Detection

## Project Overview
AgriVision AI is a Deep Learning based plant disease detection system that classifies tomato leaf images into different disease categories using Convolutional Neural Networks (CNN) and Transfer Learning.

## Objectives
- Detect tomato leaf diseases using image classification.
- Build CNN and Transfer Learning models.
- Evaluate model performance.
- Develop a prediction API using FastAPI.
- Build an interactive frontend using Streamlit.
- Deploy the application using Docker and Cloud Hosting.

## Technologies
- Python
- TensorFlow / Keras
- CNN
- MobileNetV2
- OpenCV
- NumPy
- Pandas
- FastAPI
- Streamlit
- Docker
